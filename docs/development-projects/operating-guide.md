# RBA 継続育成プロジェクト 運用基準

2026年10月30日。単発開催を増やすためではなく、本人の目的・日常の練習・周囲の支援・次の経験をつなぐための運用。

## 既存の入口を使う

公式 /ja/development-projects → 計画メモ → 既存Jotform相談窓口。参加後 /ja/after-clinic の振り返りは、本人の操作で同一ブラウザ内の計画へ引き継げる。カレンダーファイルは本人側の振り返り予定であり、RBAとの予約ではない。MY HOME COURTへの自動同期、入金照合、企画推薦、メール追客は今回実装していない。

## 相談ごとの管理（公開しない）

案件ID／成人の担当者・連絡先／本人が目指すこと／地域・年代・人数／本人・保護者・関係者の共有同意／普段の練習で試すこと／保護者・指導者・RBAの役割／候補企画／実現条件／予算と見積／対応範囲／次に連絡する日／相手・RBAそれぞれの次の行動／合意・保留・終了理由。

初回から全項目を要求しない。連絡先以外は概要で受付。子どもの氏名・診断・私的な写真・名簿を一般フォームに集めない。他チームの指導者へ無断で計画を渡さない。

## 状態と次の行動

| 状態 | 完了条件 | 次に行うこと |
|---|---|---|
| 相談受付 | 実際にフォームが送信されている | 担当者が確認。本人の希望・成人窓口・今回一緒に考える範囲を整理 |
| 目的確認 | 関係者が目指すことを共有できた | まず日常で試せることを一つ提案。企画を売ることを先にしない |
| 企画候補 | 目的に合う選択肢・地域・時期がある | クリニック／チーム支援／キャンプ／海外交流等を比較し、条件を照会 |
| 条件確認 | 担当・日程・安全・受入・費用等が確認できた | 実施内容、範囲、総額、取消条件、連絡回数を提示 |
| 合意・実施 | 相手の明示合意が記録されている | 担当・連絡方法・次回の確認日を決め、実施 |
| 振り返り | 本人・保護者・担当者の合意範囲で実施 | 試せたこと・迷ったこと・次の選択を残す。継続、調整、休止も可 |
| 保留・終了 | 理由と再連絡の要否を確認 | 追客不要の相手へ継続連絡しない。勝手な有料化・自動更新なし |

## 開催前後の標準の関わり方（各案件で調整）

- 参加前：本人が試したいテーマ、成人窓口、終了後の共有方法を確認する。
- 当日：本人が取り組みたいことを一つ選び、短い振り返りを持ち帰る。
- 2週間程度：本人・家庭・チームで試したことを確認する目安。RBAの面談は契約・合意がある案件のみ。
- 1か月程度：開催・継続を希望する案件について、相手と合意した日に企画候補を検討する。
- 3か月程度：目的に対する変化と関わり方を見直す。再参加や海外への参加を成果指標に置き換えない。

## 役割と負担

無料：初回の相談受付、概要の整理と見積。
有料：継続的な指導、定期的な助言、企画調整、個別分析等は、回数・期間・連絡方法・担当・成果物・料金を先に合意する。無制限DMや常時相談を約束しない。地域の窓口を一人決め、共通テーマ・共通資料を使う。保護者に募集・会場確保を当然の義務として課さない。

## 海外交流・留学

既存の海外ネットワークがあることを、特定日程・受入・留学制度の確約として案内しない。本人の意思、学業、語学、期間、生活、保護者同意、緊急対応、安全管理、保険、契約主体、費用・返金・渡航条件を確認する。旅行・留学手配等を行う場合は、必要な資格と役割分担を確認できる事業者と進める。入学・奨学金・選手契約・査証の取得を保証しない。

## 返信の共通骨格（送信前に案件に合わせて編集）

「ご相談ありがとうございます。今回取り組みたいのは〇〇、まず普段の練習で試せそうなのは〇〇、と受け取りました。保護者の方には〇〇、指導者の方には〇〇を一緒に確認いただければと思います。RBAからは〇〇の選択肢を検討します。現時点で日程・費用・受入は未確定です。次は〇月〇日に〇〇を確認する進め方はいかがでしょうか。」

振り返り時：「取り組んでみて、本人はどんな感想でしたか。できたことだけでなく、迷った場面も一つ教えてください。今の練習を続ける、内容を変える、別の機会を試す、少し休むことも含め、一緒に次を考えたいと思います。」

## 月1回確認する指標

相談受付数、目的の確認まで進んだ数、次の行動・日付が決まった数、合意範囲の振り返り実施数、次の企画・継続・休止の選択と理由、案件あたり対応時間。再参加率だけでなく、選手が実践できたことと現場へ残った学びを記録する。少数の回答を全参加者の満足度と表現しない。
