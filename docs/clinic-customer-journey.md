# 国内クリニック・キャンプの顧客体験運用

開始時点の確認：国内4会場の任意アンケート27件のうち26件が肯定的。参加者の満足度は母集団全体の推計ではない。山形11件中9件が定期開催、宮古7件中6件が続編を希望。申込・決済の複雑さ、事前連絡、会場案内、ゲーム実践、言語面に改善の声があった。

## 全国共通の確認指標

正本アンケート：https://form.jotform.com/263285106552052

- 満足度4〜5の件数と回答数、回答率（参加者数が確認できる開催のみ）。
- 安心感1〜2の割合、申込・決済・確認メール・会場案内などの改善項目。
- 次回の練習で試したいこと、定期開催・続編・BACKBONE・UNITEDへの希望。
- note既加入／500円・1,000円関心／検討中／不要の件数。希望は加入・売上ではない。実契約数と区別する。
- 無料RBA IDとHOMECOURT PLUSの登録・契約状況は確認可能な集計値で把握。クリック数を契約数と扱わない。

低評価があった場合はまず原因を確認し、運営上の不備があれば改善する。個別回答を望む成人が連絡先を提供している場合に限り、必要な連絡を行う。アンケート回答のみで広告配信に同意したと扱わない。子どもの氏名・健康情報・顔写真を分析結果や公開資料に載せない。
