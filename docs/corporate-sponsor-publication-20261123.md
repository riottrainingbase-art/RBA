# RBA｜企業スポンサー公開・更新運用（2026-11-23）

## 公開経路（混同しない）

- `/ja/sponsors`：全体の公式案内。公開済みの地域連携・過去の企業協賛と、現在の月額企業広告を区分して表示
- `/ja/sponsor`：企画協賛の既存説明・合同会社KHMの紹介ページ
- `/ja/support`：月額企業広告の申込・既存広告主一覧。契約・決済主体は既存Stripe／DBのまま
- `/ja/gream-sendai/partners`：GREAM仙台の地域広告・ウェア広告。全国広告とは別契約
- `/ja/national-tour`：全国育成ツアーの企画協賛。開催日・実績・掲出権を別途合意

## 企業登録の区分

1. **営業候補・紹介依頼・打診済み**：社名を含め、公共GitHub・公開サイトには保存しない。非公開の営業台帳で管理。
2. **協議中・見積中・契約承認待ち**：契約条件・名称・デザイン・ロゴ権利を確定するまで公開しない。
3. **契約済み・入金未照合**：契約書の存在だけで「協賛中」表示しない。
4. **現在の月額広告**：`rba_advertisers` が `published=true`、`paid_verified=true`、`consent_confirmed_at`が存在し、`display_until`が未来の場合のみ `getAdvertisers()` で表示。終了・期限切れ・決済失敗後は台帳上の契約条件を照合して表示解除。
5. **個別の企画協賛・現物提供**：提供内容・期間・掲載名義・画像権利・提供完了証拠を別途確認。現物提供を現金協賛、単発協力を年間協賛と表現しない。
6. **過去の協賛**：実施・契約期間とともに過去実績欄へ掲載。継続中と誤認させない。

## 公開までの証拠ゲート

- [ ] 正式商号・公式URL確認（https優先、URLの所有者・リンク先を目視）
- [ ] 契約・協力範囲・開始終了日、媒体、報告・返金条件の確認
- [ ] 入金の必要な広告はRBA名義の本番Stripe原取引を照合（送信メールやフォーム登録だけでは代替しない）
- [ ] 会社担当者が公開の権限を持つこと、社名・紹介文・リンクの掲載許諾
- [ ] ロゴは正式素材とRBAサイト利用の書面許諾。許諾前にGitHubの`public/`へ置かない
- [ ] スポーツイベントの掲出・ウェア等は施設・大会規則と個別承認を別途照合
- [ ] 本番公開前にスマホ表示・リンク・期間・表記を確認し、公開開始を記録
- [ ] 更新・終了・解約・撤回時の削除対象と既発行レポートの扱いを記録

## 実装上の境界

- `lib/public-sponsors.ts` は**すでにRBAサイトで公開されていた2つの実績・紹介のみ**を初期登録。ここは公開GitHubなので非公開連絡先・契約書URL・入金額・個人名を保存しない。
- 新たな企業を追加する際には契約・掲載文・企業許諾の3条件を確認して、レビュー付きPRで更新する。ロゴは別途 `logoUsageApproved` と `/brand-logos/` 配下の承認済み素材のみ。
- 361°は商品提供・クーポンの協議があるが、現行の公式ロゴ・掲載文言・期間の許諾が確認できるまで新規表示しない。 `lib/brand-partner-361.ts` の既存ゲートは変更しない。
- サン食品は11月14日の物品提供実績が確認できるが、月額広告でも2026年12月の年間現金協賛でもない。新規公開許諾と範囲確認まで企業名・ロゴの追加掲載をしない。
- 中神工務店の2026年3〜8月の契約は「過去の協賛」。2026年11月の月額企業広告は別の契約・掲載手続き。フォームのロゴ許諾と初回入金報告があっても、最終確認前に現在の広告一覧へ登録しない。
- KHMはすでに`/ja/sponsor`で企業紹介中であるため、既存の公開紹介へのリンクとして表示。契約期間・協賛金額・新たなロゴ利用権を推定しない。

## 更新ルーチン

1. 非公開の営業台帳で営業・承認・入金・掲載・期限・更新・解約を照合。
2. 月額広告はDB側の実条件を確認（公開コードから入金・同意を推定しない）。
3. 企画協賛の新規公開はレビューPRに限る。`node --test tests/public-sponsors.test.mjs` を実行。
4. Vercel previewで新規パートナーの表記・logo URL・導線をレビューし、承認後に本番公開。
5. 毎月、公開広告の期限、広告レポート、退会・未払い、協賛先からの削除依頼を確認。

**この導入PRは、新たな営業先や未承認ブランドの公開、追加請求、決済リンク発行、Stripe契約・DB書込を行わない。**
