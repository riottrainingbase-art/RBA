# RBA IPO Readiness Control Plane

This file is an operating-control document, not a representation that RBA is currently IPO-ready.

## Priority 1 — Production source control
Status: IN PROGRESS

Required evidence:
- current Vercel production source recovered
- GitHub main matches production baseline
- v6-final-candidate kept separate
- Preview build passes
- PR records final production change
- rollback deployment recorded

## Priority 2 — Safeguarding accountable owner
Status: BLOCKED

Do not invent a person.
Required:
- primary safeguarding officer
- deputy/escalation route
- active status
- contact details
- training evidence
- review date

## Priority 3 — Authoritative capacity
Status: BLOCKED

Capacity-controlled offers must not accept uncontrolled checkout when capacity is unknown.
Keep fail-closed behavior until real capacity is confirmed.

## Priority 4 — Governance approval
Status: BLOCKED

Core documents:
- Terms of Service
- Privacy Policy

- International Travel Terms

Professional review is required before representing these as legally complete.

## Priority 5 — Organization standards
Status: BLOCKED

Standards should be approved/published with version, effective date and review date.

Status: IN PROGRESS
