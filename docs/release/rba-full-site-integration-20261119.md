## 4. 今回の安全移植（新規統合PRの範囲）
- 本番系リリースブランチを起点にした新規 feature ブランチで、既存の重要機能を残して以下を移植。
- `/ja/supporters`：月500円／1,000円案内、無料記事との違い、会員特典・退会・二重入会の説明、実践サンプル。
- `/ja/development-check`：7日間の無料観察ガイド。個人情報入力なし。応援加入は任意。
- `/ja/support`：個人note支援と企業Stripe広告を区別する案内。
- クリニック申込後、参加後フィードバック、鹿児島クリニックページ：任意の月額サポート案内（必須チェックボックスなし、決済フローには介入しない）。
- `NoteBridge`：公開系のJOURNAL／note／MY HOME COURTの三層設計を維持し、公式note加入URLと無料ガイドのみ追加。
- 公開系から `main` にある未検証API・決済・認証変更を持ち込まない。
- 新規の `tests/release-support-and-registration.test.mjs` をCI対象として扱う。
