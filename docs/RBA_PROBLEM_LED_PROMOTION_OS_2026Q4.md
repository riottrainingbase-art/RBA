# RBA Problem-Led Promotion OS — 2026 Q4

## Role of problem-led content

RBA should keep problem-led content as a primary acquisition channel.

The purpose is not to "win arguments" or provoke for its own sake. The purpose is:

**違和感を言語化する → 根拠で整理する → RBAの実践を見せる → 次の行動へつなぐ**

A strong RBA post should make a parent or coach think:

> 「これ、うちのチームのことかもしれない。」

That recognition is the top of the funnel.

## Editorial guardrails

Every issue-led post must pass these five checks:

1. **Target the system, not a child or identifiable coach.**
2. **Separate evidence from RBA's interpretation.**
3. **Avoid universal claims when evidence is context-specific.**
4. **Give an alternative, not only criticism.**
5. **Use one CTA only.**

Avoid:
- naming/shaming individuals
- "all coaches do this" language
- unsupported medical claims
- rage-bait headlines that the article cannot support
- attacking a team merely for winning
- positioning RBA as the only correct answer

## Three issue families

### A. CHILD-FIRST CONTRADICTIONS
Questions that expose a gap between adult convenience and child development.

Examples:
- 試合に出られない小学生は、本当に育成されているのか？
- 「勝つためだから」で役割を固定していいのか？
- ベンチに座っている時間は、何を学んでいるのか？
- 全国大会出場は、チーム全員の育成成功を意味するのか？
- 大人の勝利欲が、子どもの出場機会を奪っていないか？
- 「嫌なら辞めればいい」で育成環境の問題を終わらせていいのか？

Primary audience: parents / youth coaches
CTA: JOURNAL or Development Guide

### B. EVIDENCE VS TRADITION
Questions where inherited practice should be checked against evidence.

Examples:
- 練習量は、多いほど上手くなるのか？
- 罰走でバスケットの体力は本当に伸びるのか？
- 筋トレをすると身長が伸びない、は本当か？
- 試合を増やせば判断力は伸びるのか？
- シュートフォームだけ直せばシューターは育つのか？
- 低学年からポジションを固定する合理性はあるのか？
- 説明が長いほど、選手は理解するのか？
- スキルドリルを増やせば試合で使えるようになるのか？

Primary audience: coaches / serious parents
CTA: full article, D-HUB, Torsten, Development Guide

### C. SYSTEM / STRUCTURE
Questions that move RBA from commentator to thought leader.

Examples:
- スポ少は、誰のために存在しているのか？
- U12の大会数は、育成に対して多すぎないか？
- なぜ出場機会を制度で守る国があるのか？
- 「強豪校に行けば伸びる」という進路選択は合理的か？
- 育成年代で全国大会を頂点に置く設計は何を生むのか？
- 地域によって学ぶ機会が変わりすぎていないか？
- コーチ教育が個人の善意に依存していないか？
- 海外遠征は、本当に育成になっているか？
- 保護者負担が大きいほど良いチームなのか？
- 「所属チーム以外で学ばない」文化は誰のためか？

Primary audience: parents / coaches / organisers / sponsors
CTA: RBA philosophy, Host RBA, partnership, Japan × Asia

## The six-part post formula

### 1. Hook
One sharp question.

Example:
**試合に出られない小学生は、本当に育成されているのか？**

### 2. Shared reality
Describe what people already see.

> 10人以上登録されていても、接戦になるほど出る選手は固定される。

### 3. Evidence / reference
What research, official guidance or comparative systems suggest.

Keep it short in social. Link to the full article for nuance.

### 4. Structural explanation
Explain why the behaviour happens.

Example:
- tournament incentives
- short-term evaluation
- coach fear of losing
- roster size
- lack of rotation norms

### 5. Alternative
Give one practical alternative.

Example:
- planned rotation
- minimum participation rule
- game design
- development blocks

### 6. One CTA
Only one.

Examples:
- 「出場機会について、全文はRBA JOURNALへ」
- 「今参加できるRBA NEXT COURTを見る」
- 「チームの育成環境を相談する」

## Content ladder

One issue should become at least four pieces.

### Day 1 — Provocation
Carousel / Threads
Goal: reach + shares

### Day 2 or 3 — Evidence
JOURNAL / note
Goal: trust + search

### Day 4 — Field Proof
What RBA does in practice
Goal: credibility

### Day 5–7 — Action
NEXT COURT / RBA ID / Host RBA
Goal: conversion

Never write four unrelated posts when one issue can become four stages.

## Recommended mix

Weekly:
- 2 strong issue-led posts
- 1 evidence / explainer
- 1 field proof
- 1 offer / next step

Monthly share:
- 40% issue / structural
- 25% field proof
- 15% education
- 10% Japan × Asia

## Success metrics

Do not optimise for likes alone.

Track:
- shares per 1,000 impressions
- saves per 1,000 impressions
- profile visits
- link clicks
- JOURNAL dwell / next click
- RBA ID registrations
- LINE additions
- application starts
- paid conversions
- repeat participation

A post with fewer likes but more saves, profile visits and RBA ID registrations is strategically stronger.

## Comment strategy

RBA should not fight in comments.

Use:
- clarify the claim
- acknowledge legitimate operational constraints
- ask a better question
- link evidence when useful
- leave personal attacks unanswered or moderate appropriately

Good reply:
> 接戦での采配が難しいこと自体は理解しています。今回問いかけたいのは「育成年代で、誰にどの経験を渡す設計にするか」です。

Bad reply:
> だから日本はダメなんです。

## Conversion principle

Problem-led content creates the first emotional opening.

But RBA must always complete the journey:

**問題提起 → 根拠 → 実践 → 参加 → 継続**

If the system stops at debate, it builds attention but not an asset.

If the system reaches RBA ID / NEXT COURT / Host RBA, the same reach becomes a durable audience and revenue channel.
