## 2. 価格根拠・市場の位置づけ

2026-11-16時点で確認できる公開例：
- GENTIL BANDITのハンドペイント文字加工：税込3,300円〜。https://gentilbandit.com/ハンドペイントカスタム/
- HANSの衣類への直接ペイント加工：5,000円〜、はがきサイズ約5,000円、A4約8,000〜11,000円。https://charcoal-ltd.co.jp/event/hans-pop-up/
- 作家の手描きTシャツ完成商品：16,500円（衣類込み）。https://minne.com/items/32639018
- 一点物の手描きパーカー完成商品：30,800円（衣類込み）。https://guernika.jp/products/hand-painted-hoodie-white-13

後半2件は「加工代だけ」の直接比較に使わない。

RBAの試算上の目安（メーカー確定見積ではない）：
- SIGNATURE：税込4,400円 → 税抜換算4,000円（10%仮定）−作家45分×2,500円/h（1,875円）−消耗材300円−検品・特別梱包250円−不良引当350円−運営管理400円−決済3.6%（158円） ≒ **貢献額667円**。
- ARTIST：税込8,800円 → 税抜換算8,000円 −作家100分×2,800円/h（4,667円）−消耗材500円−検品・梱包350円−不良引当700円−管理800円−決済317円 ≒ **貢献額666円**（ロイヤリティ別）。
- 目標貢献率20%を満たすには、上記仮定でSIGNATURE約**5,300円以上**、ARTIST約**10,800円以上**が目安。費用や税務、作家報酬で変動する。あくまで内部検討。

**結論：+4,400円は販売促進力を重視した下限候補だが、想定作家報酬と不良リスクを含めると余裕が小さい。** 制作者との作業時間が45分を超えるなら、+5,500円または+6,600円も現実的な比較候補にする。画像のような広い胸全面への自由な書き込みを+4,400円の対象として誤認させない。

## 3. 制作者に相談する内容

**制作**：白TEE・黒フーディそれぞれ試作品1点、可能なら洗濯耐久試験用の同型1点を追加。胸上の控えめな手書きと、画像参考の筆跡が大胆なアートの2パターン。

**書き方**：直接手書きか、版画・印刷等を含むかを明確にし、購入者に誤認が生じないよう区別。ボールペンや通常の墨ではなく生地用材料を使用し、硬化方法を素材ごとに確認する。

**契約**：本人の参加合意、筆跡と原画の商用利用、Instagramでの掲載・二次使用、作品ごとのクレジット、通常版との価格差、試作費、個別加工費、再制作、キャンセル、海外販売時の権利を文書化。

**サンプル**：洗濯1・5・10・20回で写真記録、色移り・ひび割れ・摩擦・洗濯表示の変更要否を評価。工程ごとの時間と費用を測る。

## 4. 実務上の受付フロー（発売後に限る）

1. アイテムとサイズを選ぶ → 手書き加工は「なし」が初期値。
2. 「追加する」を選んだときだけ追加料金・加工位置・文章上限・作家の表現範囲を表示。
3. 表示の下に入力欄、全文確認チェック、変更可能期限、不可事項を設ける。
4. 支払い前の最終確認で商品代・手書き追加料金・税・送料・納期・キャンセル・返金条件を表示する。
5. Stripe決済後、文章や制作指示はRBAの非公開受注データに記録。SNS公開せず、支払いの実在性をWebhookで確認。
6. 作家による下書き確認（契約上必要な範囲）→ 描画→定着→検品→発送。
7. 遅延時は期限到来前に連絡し、購入者の希望に応じて履行・合意変更・返金処理等を適切に判断する。

## 5. 公開前に必ず揃えるもの

- 作家と責任の分界点が決まった正式契約

- 追加料金・作業範囲・上限点数・納期・返品条件の最終承認
- 不良・文言違いの再制作、返金処理、注文承諾通知のテスト
- 作家名公表・写真使用・広告表現の本人承認
- Metaカタログ登録時には本体価格と加工料金が混乱しない表示
