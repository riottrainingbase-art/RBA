# RBA note 月額50万円 成長計画（2026年11月19日）

## 目的と事実
- 目的: 全国・国際の育成、指導者教育、学びを続けるために、任意の月額応援を増やす。
- 運用済みの案内: https://riotbasketballacademy.com/ja/supporters
- 決済: note公式メンバーシップ https://note.com/rba_official/membership/join
- 表示されている2プラン: 月500円（活動応援）、月1,000円（育成記事）。**単発課金、寄付控除、チーム指定配分と混同しない**。
- 特典と更新・解約条件は**note側の実際の画面が最優先**。このレポジトリからnoteの販売設定を操作したことにはしない。
- 実在する会員数・入会数・解約数はnote管理画面の承認済みデータがあるときだけ記入。推測値は使わない。

## ゴール
- 売上MRR（手数料控除前）= 500円プラン有効会員数×500 + 1,000円プラン有効会員数×1,000
- 500円プラン500名 + 1,000円プラン250名 = **月500,000円（合計750名）**
- 注意: これは目標シナリオで、現在の会員実績を示さない。
- note公式の手数料: 購入者の決済方法に応じた事務手数料の後に、メンバーシップのプラットフォーム利用料10%。振込手数料も別。したがってMRR=入金額ではない。
- 正式ルール: https://www.help-note.com/hc/ja/articles/360011358873
- 請求日・継続課金の詳細はnote最新案内を参照: https://www.help-note.com/hc/ja/articles/60464028042009

## 入口
1. 無料: RBA JOURNAL記事で育成の課題と具体的な学びを提供。
2. 共感: /ja/supporters でRBAが何を続けたいか、500円と1,000円の違い、使途の考え方、FAQを説明。
3. 有料: note公式入会へ。サイト内で課金したり個人情報を取得したりしない。
4. 継続: 実際の活動の振り返り、問い、次の取り組みを継続して届ける。**実施していない特典を約束しない**。

- 主要訴求: 「月500円から、日本の育成を変える仲間に。」
- 500円向け: 「何か変えたい。でも大きな協賛はできない。そんな方の気軽な参加。」
- 1,000円向け: 「応援に加えて、保護者・指導者として育成を学ぶ。」
- CTAは常に RBA公式応援ページ /ja/supporters を基本にする。noteに直接送る場合も公式URL以外を使用しない。
- 「サポートを強制しない」「会員資格だけでクリニック無料にはならない」「既存のHOMECOURT/D-HUBとは別の任意加入」を明示。

## 販促の許諾と安全
- RBAサイト・公式SNSの自社投稿を基本とする。
- 既存の連絡先に対する一斉営業はしない。配信同意、重複、停止要請、関係性を確認してから連絡。
- 有料広告は予算・ターゲティング・クリエイティブの別承認後に実施。
- 子どもの顔、名前、怪我、家庭事情、会場の非公開情報を同意なく素材化しない。
- 協会・リーグ・クラブの公式公認・協賛を装わない。
- note運営管理画面を確認せず、特典の追加、無料期間設定、会員数取得や売上の確定を行ったと表現しない。
