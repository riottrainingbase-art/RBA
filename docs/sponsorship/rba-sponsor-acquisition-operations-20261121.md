# RBA 企業スポンサー・協賛｜営業から契約・活動報告までの運用（2026-11-21）

## 基本方針

企業の担当者が安心して相談できる、分かりやすく丁寧な受付を徹底する。協賛の額・実績・露出は誇張しない。「支援します」という返信を契約や入金と混同せず、**相談 → 条件確認 → 見積・提案 → 書面合意 → 請求・決済 → 掲載/実施 → 活動報告**を分離する。

## 企業リードの管理

### 顧客対応の状態（集計・運用の正本）
1. `new_inquiry`：成人の業務担当者から、本人の意思で問い合わせ／返答許可が届いた。
2. `needs_qualification`：企業の正式名称、実在・公開URL、地域、希望内容、過去のSENT/INBOX/STOP・関連会社／別ドメインを未確認。
3. `qualified`：過去の重複・不達・辞退を解決済み。目的・金額・広告媒体・担当者の意向を確認。
4. `meeting_scheduled`：日付、議題、相手、承諾済み会議URLが確定。
5. `proposal_sent`：見積や契約の素案を先方へ提示した事実を確認。
6. `terms_agreed`：価格・期間・使途・ロゴ・広告対価・キャンセル／中止・税区分を**双方で書面合意**。
7. `invoice_or_checkout_issued`：正式契約に対応する請求書・決済導線が発行された。**入金済みではない**。
8. `payment_verified`：金融機関／決済側で対象請求の入金成功を確認。
9. `delivery_in_progress`：ロゴ許可、契約された広告・現物・活動を実施。
10. `reported_and_renewal_due`：実施URLと事実に基づく報告の提出、更新の確認。
11. `declined_or_stop` / `bounce_or_hold`：断り・停止要請、または不達。**別アドレス・関連部署への迂回営業は禁止**。

重要：**送信済み ≠ 先方到達 ≠ 商談 ≠ 契約 ≠ 入金**。会議開催だけで確定金額に加算しない。

### 初回の問い合わせ対応

- 受付を読んだら同一ドメイン・企業別名・過去Gmail・既存CRMを照合する。
- 可能な限り2営業日以内を**社内目安**として、人が確認して返信する（対外的な対応保証は行わない）。
- 相手に負担をかけず、希望があれば2ページ程度の社内説明用資料、媒体・価格・税区分・掲載回数等を送る。
- 顧客の許可なしに月額広告の自動課金URLへ強制誘導しない。
- 返答がない場合、無制限の催促や他部署への営業を行わない。拒否・辞退・不達・停止希望は優先的に登録する。
- 対外文書には事業に関係のない私的情報を含めない。

### 面談時の標準確認事項

1. どの地域・年代・育成活動に支援したいのか
2. 広告の対価を求めるのか、寄付・現物か、共同企画か
3. 想定予算、決裁権者・稟議期限・希望開始時期
4. 企画名、開催／実施の確定状況、補助枠の可否
5. 確定できる掲出先・表示期間・ロゴ許可・媒体の規則
6. 合意できる活動報告の項目、子どもの肖像とプライバシー
7. 通常の請求書／領収書・税区分・中止時の精算・更新方法

### 守るべき条件

- 未成年者の氏名・連絡先・健康情報・未承諾の写真を企業に渡さない。選手に広告出演を強制しない。
- 広告宣伝費扱いや税額控除を断定しない。RBAの適格請求書発行状況は契約前に再確認する。
- 企業名・ロゴの掲載は許可後に限る。既往の一度の協力で継続スポンサーと表示しない。
- 計画中の国際大会・ツアーを開催決定と誤認させない。RBAの名前だけでFIBA・JBA・自治体の公認・共催を装わない。
- 月額広告の定型条件と地域広告の年契約を混同せず、他企画の広告契約から自動切替えしない。
- 個別スポンサーの契約・振込・公開は、先方による正式承諾を確認してから行う。

## 進捗指標

- `unique_qualified_inquiries`: 重複除外後の適格な企業からの問い合わせ件数
- `meetings_held`: 実際に実施した商談件数
- `proposals_delivered`: 正式提示を確認できた提案件数
- `signed_contracted_value`: 双方書面合意後の契約額（単年・複数年は区分）
- `paid_received_value`: 入金成功が証明された総額（税区分・契約ごと）
- `in_kind_agreed_value`: 原価・市場価値の算定根拠がある現物協力、現金と別枠
- `sponsorship_delivery_rate`: 契約済みの成果物に対する公開・報告完了率
- `stop_or_bounce_blocks`: 辞退、不達・送信停止によって除外した数

推計広告到達数、返事だけの協力意思、資料作成・SNS下書きを売上に含めない。
