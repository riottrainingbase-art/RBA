# MY HOME COURT｜全国開催・無料先行受付 運用基準

最終更新: 2026-11-19
状態: 先行登録フォーム公開、サイト改修はプレビュー／リリース確認後に本番反映

## 目的

RBAのクリニック、Development Camp、指導者講習、RBA UNITED等について、全国47都道府県から*開催希望・参加意向*を受け付ける。会場未確定の企画を確定募集や支払受付と誤認させない。全国での開催機会を増やすための需要把握が目的であり、全国での開催決定を意味しない。

2. 全国開催の説明: https://riotbasketballacademy.com/ja/my-homecourt/nationwide

5. 個人情報の取り扱い: https://riotbasketballacademy.com/ja/policies

韓国・仁川2027向けフォームは https://form.jotform.com/263207310187047 で、一般の全国開催希望フォームと混ぜない。大会の年齢・登録人数・安全管理・費用・旅行契約条件は独立して管理する。

## 受付の定義

- **先行案内登録:** 無料、希望受付人数の上限なし。地域での参加・開催・優先権・席確保・申込・支払の確約はない。
- **開催検討中:** 主催候補／施設候補／会場候補の段階。日程・参加費・申込先を確定表示しない。
- **開催確定:** 会場、日時、対象、運営責任者、参加条件、料金、キャンセルポリシー、安全・保険、定員を確認済み。
- **正式募集:** 開催確定後、個別の企画専用フォームと必要な決済を設ける。先行案内登録から自動で有料申込へ変換しない。

「選考」は通常の先行受付の名称に使わない。国際大会の公式な選抜・資格審査が実際に必要な場合には、確定後の**別の正式募集要項**でのみ説明する。

## 登録後の運営（人による確認）

フォームは主たる記録源。新規登録の原本は削除しない。将来のCRM連携時も、元のJotform送信IDをキーとして重複登録しない。

| 管理項目 | 目的 |
| --- | --- |
| 送信ID・受付日 | 重複排除・履歴 |
| 都道府県／地域 | 開催候補の需要把握 |
| 希望年代・興味プログラム | 内容の企画 |
| 参加者／指導者／開催協力者 | 適切な案内先を判定 |
| 希望時期・会場協力 | 主催側への確認 |
| 個人情報同意・追加案内同意 | 通信の適法な運用 |
| 対応状態・最終確認日 | 対応漏れ防止 |

推奨する内部対応状態は「新規」「地域・年代を確認」「主催候補と調整」「開催確定・案内可」「別企画へ移行」「対応終了」。受付順で参加優先権を与えない。開催できない地域も登録拒否・募集打切りとはせず、配信不要の希望には従う。

## 先行案内の注意

- 希望した人への必要連絡と、任意のニュースレター・営業案内は別の同意として扱う。任意同意がない場合は広告的な一斉配信に含めない。
- 未成年の参加希望は保護者名義で登録。初期希望登録では子どもの氏名、生年月日、病歴、食物アレルギー等を取得しない。
- 外部参加者を勝手に招待・登録しない。Torsten Vol.2の送信禁止対象に案内・招待を送らない。
- 日時・会場・定員の未確定を黙って埋めない。企画検討中と正式募集を画面・メール・決済のすべてで区別する。
- 広告文言として「全国47都道府県で開催決定」「残り○枠」「早い者勝ち」「選出確定」を使わない。

## 週次レビュー指標

- 新規の希望登録件数、都道府県ごとの回答件数（関心人数＝確定参加人数ではない）
- 参加希望と開催協力の割合、年代別・プログラム別の希望
- 会場協力候補の確認件数、開催検討から開催確定へ進んだ件数
- 正式募集開始後の申込への転換件数（先行登録の申込確約ではない）
- 重複登録、配信同意の不備、誤った定員・日程表示の件数

本人の明示的な許可と正式な運用設計が整うまで、フォーム送信に伴う対外営業メール・予約・決済の自動実行は行わない。
