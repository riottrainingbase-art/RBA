## 2. 実現条件と募集の順番
1. 必要な学年・人数・指導者・保護者の送迎・駐車・安全管理・参加費設定を明示した実施案をまとめる。
2. 施設名義・用途・有料スクールの利用可否を確認。既存契約の名義利用、第三者への無断転貸、許可目的外利用はしない。
3. 会場承認と具体的な日時・単発体験費用・定員・担当者の確定後に、参加者への正式体験日案内を開始する。
4. 無料相談の希望者に、条件・価格・必要な同意・返信期限を個別に知らせる。空き枠を偽らない。
5. 体験後に加入を選んだ保護者のみ、承認済みの正式申込・規約・決済を案内する。
6. 支払い・契約・初回出席は別々に確認する。再送禁止先と辞退先の連絡先は削除・非送信の運用にする。

## 3. 100名を収容する現実のキャパシティ
U15 SKILL UPは定員25名と案内されているため、これだけでは100名に届かない。100名を支えるには複数の日時・会場と指導スタッフが必要。
**仮の構成例**：定員25名の4クラス = 最大100名（U12、U15、女子スキル、別曜日等）。実際の定員は床面積、コート、指導員人数、男女・学年、保険と施設条件で決め直す。定員を先に宣伝しない。
**需要計画の仮定（実績ではない）**：問い合わせ→体験日確定50%、確定→参加80%、参加→入会50%なら、入会100名に必要なユニーク相談は約500件。6か月で達成するなら約84件/月の新規ユニーク相談が必要。退会・紹介・兄弟入会等は未考慮。個別のKPI数値は4週間の実測で更新する。

## 5. 集客ループ
公式Instagram/Threads → https://riotbasketballacademy.com/ja/links → https://riotbasketballacademy.com/ja/sendai-school → Jotformの無料相談 → RBAが個別に返答。

Jotform「このスクールをどこで知りましたか？」を使い、流入の自己申告を集計する。クリック数とフォーム提出数は別イベントであり、クリック＝入会ではない。

## 6. 見込み客の管理（個人情報はGitHubへ保存しない）
毎回「相談フォームを受領したか」「返信済みか」「会場・日程の承認があるか」「体験日提案したか」「保護者が同意したか」「体験したか」「入会済か」を個別に記録。
推奨ステータス：
NEW → ACKNOWLEDGED → VENUE_PENDING → OFFER_SENT → TRIAL_CONFIRMED → ATTENDED → JOINED
分岐：DECLINED / WAITLIST / NO_RESPONSE / UNSUBSCRIBED。
コンテンツ制作・キャンペーン分析には人数と集計値のみを使う。選手の健康情報、学校名簿・保護者メールアドレスなどを広告プラットフォームへ無断共有しない。

## 8. 会場問い合わせの要件
候補先に初回メールまたは電話で「日時」「人数」「有料指導」「主催名義」「使用区分」「バスケゴールの高さ」「入退館・駐車」「必要な安全確認」「使用料総額・取消規定」をまとめて確認する。
仙台市市民センターの体育館・ホールは夜間17:30〜21:00の時間帯区分で貸出（施設ごとに機能は異なる）。公式案内 https://www.hm-sendai.jp/siminc/guidance/
市民センターのバスケットコートはミニバス仕様が多く、U15正規ゴール対応は施設ごとの確認が必要。仙台市FAQ https://guide.callcenter.city.sendai.jp/hc/ja/articles/5130140020894-
施設利用には登録・抽選・申込期限があり、一般利用者の予約枠を勝手にRBAの体験会に転用しない。都度の必要資料・減免要件・参加費の扱いは先方に照会する。
