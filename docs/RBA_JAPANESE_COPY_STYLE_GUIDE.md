# RBA 日本語コピー・スタイルガイド

更新日: 2026-10-06

## 目的

RBAの日本語は、理念を強く保ちながらも、保護者・選手・指導者が一読で意味を理解できることを最優先にする。

RBAらしさは抽象語の多さではなく、育成に対する考え方と、実際に何をするかが明確であることから生まれる。

## 基本原則

1. **抽象語より具体語**
   - 「育成機会」より「クリニック・キャンプ・スクール・交流」
   - 「次の一歩」より「次に参加する活動」「次の練習で試すこと」
   - 「入口」より「ページ」「窓口」「活動」「申込」

2. **「つなぐ」を連続して使わない**
   - 記録する
   - 確認する
   - 試す
   - 学ぶ
   - 参加する
   - 振り返る
   - 相談する
   - 組み合わせる
   など、実際の行動に置き換える。

3. **「整理する」は、本当に整理する場面だけ**
   - 情報をまとめる → 「まとめる」
   - 課題を見つける → 「確認する」「優先する課題を決める」
   - 相談内容 → 「分かる範囲で教えてください」

4. **日本語ページでは、固有名詞以外の英語を増やさない**
   残してよい例:
   - RBA
   - MY HOME COURT
   - HOMECOURT PLUS
   - D-HUB
   - RBA UNITED
   - Development Camp
   - S&C
   - 3x3

   原則日本語にする例:
   - Coach → 指導者
   - Team → チーム
   - Camp → キャンプ（固有名称を除く）
   - Clinic → クリニック
   - Organizer → 主催者・団体
   - Vision → 将来構想
   - Basketball Program → バスケットボールプログラム

5. **1文1メッセージ**
   長い事業説明より、短い文を2つに分ける。

6. **保護者向けページは先に事実**
   優先順位:
   1. 対象
   2. 日時・場所
   3. 費用
   4. 申込方法
   5. 安全・キャンセル
   6. 育成方針

## 商品・サービス名称

- **MY HOME COURT**: 無料の自分専用ページ / RBA IDで利用
- **HOMECOURT PLUS**: 月額3,300円の有料プラン
- 「月額HOMECOURT」「有料HOMECOURT」は使用しない
- **RBA U15 SKILL UP SCHOOL** は SCHOOL と表示する。CLINIC と表示しない。

## CTAの基準

優先:
- 活動を探す
- 詳細・申込を見る
- 公式申込へ
- RBAに相談する
- チーム・団体向けを見る
- 海外交流を見る
- MY HOME COURTを見る
- HOMECOURT PLUSを見る

避ける:
- このコートに挑戦する
- 次の一歩へ
- 入口へ進む
- つながる
- まずここから（説明なしで単独使用）

## RBAらしいコピー

残してよい強い表現:
- 子どもの未来から、育成を考える。
- 勝つことと、育てることは同じではない。
- 育つ場所を、住んでいる場所で決めさせない。

強いコピーの直後には、具体的な説明を置く。

## SEO / SNS

- 検索結果だけ読んでも、ページ内容が具体的に分かるようにする。
- 「プラットフォーム」「育成機会」だけで説明しない。
- クリニック、キャンプ、スクール、指導者学習、海外交流など具体語を含める。
- 「日本最大級」等の規模主張は、客観的に裏付けられる場合だけ使う。

## 数字・料金表記

- 月額: 「月3回／月額7,700円（税込）」
- オンデマンド: 「30日間オンデマンド」
- 宿泊: 「宿泊・食事付き」
- 税込／税別は実際の決済条件に合わせ、推測で追加しない。
