# RBA ESSENTIALS | 販売と製作・発送の役割分担
2026-11-16 更新 / 内部運用案 / ユーザー指定を反映

## 結論
RBAが購入窓口・SNSマーケティングを担当し、りささんにデザイン・製造・品質管理・梱包・発送の実務を一括して委ねる2者分担を採用する。

**重要**：ユーザーは分担方針を決めたが、りささんの受託条件、報酬、送料負担、顧客情報の受け渡し方法、作業能力・法的契約について第三者の署名済み合意が確認できたわけではない。これは実行前の役割設計であり、事前承認のない権限付与・注文データ共有・有料注文公開を意味しない。

## 責任分担（RACI）

| 工程 | 実務の主担当 | 承認・対外責任 |
|---|---|---|
| ブランド方針、商品ラインナップと価格決定 | RBA | RBA |
| Instagram投稿、広告、公式Web商品ページ | RBA | RBA |
| 注文受付、Stripe決済、注文番号・未入金監視 | RBAのサイト/システム | 販売者（RBAを想定、要法的表示） |
| 生地・ボディ選定、製造業者手配、ワッペンと首元タグ | りささん | りささんが製造工程を管理、RBAがブランド仕様承認 |
| サンプル検品、正式サイズ実寸、洗濯耐久試験 | りささん | RBAが販売前の商品品質を確認 |
| 入金済み注文の製作指示、サイズ別数量集計 | 自動的な非公開注文管理 | りささんが受領・履行 |
| 製作・仕様不一致チェック・検品 | りささん | りささんが工程内の品質責任、法定の対消費者責任は販売者 |
| 梱包、配送会社・追跡番号、発送連絡情報 | りささん | RBAは購入者への適切な発送連絡を担保 |
| 誤配送・不良・遅延、交換・再製作 | りささんが製造・物流実務 | RBAが返金・購入者対応を監督（法律上の販売者義務が残る） |
| 売上から必要費用を差し引いた利益の育成充当 | RBA | RBAが証憑・会計処理を記録 |
| 直筆カスタムの作画と作品許諾 | りささん（別契約・別工程） | 権利と報酬に合意するまで販売しない |

## 注文受付から発送の実務フロー

1. RBAのInstagram投稿→RBA公式ページ→商品・サイズ・数量選択→購入条件・税込総額・確定納期表示→Stripe決済。
2. Stripe署名済Webhookで実際の支払済み注文だけをRBA HOMECOURT非公開注文台帳に登録。未入金は製作しない。
3. 受注台帳は `受注 → 製作準備 → 製作中 → 検品 → 発送準備 → 発送済 → 配達済` を管理し、担当者の更新を時刻付きで保存。
4. りささんに渡す情報は「必要な注文番号、商品型番、サイズ、点数、期限、必要な配送先」だけ。**口頭や公開DMに住所・電話・顧客情報を貼らない**。安全な専用権限／限定共有方法は本人確認・契約後に実装する。
5. りささんから追跡番号・発送日を管理画面に返し、RBAのシステムが購入者に発送連絡。RBA代表が日々注文単位の手入力や製造手配を行わない。
6. 不良・誤配送・納期遅延発生時はりささんが製造・物流の一次調査。RBA（販売者）は返品返金の法的責任や最終意思決定を放棄しない。
7. 一か月の納期は希望条件。製造能力と配送日数の裏付けが取れた後で具体的な日付・期限を消費者に表示する。

## りささんと文書で決める条件
- 担当範囲（通常Tシャツ・上下セットと、将来の直筆企画を混同しない）
- デザイン・版下、ロゴの正しい使用方法、商用利用権と作品写真利用の範囲
- 原材料費、型代、1着の製作単価、最低ロット、サンプル費、梱包・配送費
- 在庫保管先、注文の確定時点、入金確認〜製作開始のSLA
- 発送までの最大日数、納期遅延の連絡期限、日々の製造可能数
- 不良・誤製作・誤配送・紛失・未着時の費用負担、顧客返品・返金を処理する手順
- 個人情報の取扱い（受託者、アクセス管理、再委託、保存期間、削除、事故時の報告）
- 精算サイクル（納品済み／受注時など）、報酬・支払証憑、契約解消時の未発送注文責任
- 作家名や本人写真を広告に掲載する許諾、Instagram誘導先やブランドの権限

## 制作を始めるための確定条件
- りささんによる役割・原価・納期・発注後の流れの正式承認
- サンプルと正規公式ロゴ（縦約4cmワッペンは検討値）・首元タグ・洗濯表示
- 商品別の税込価格・送料・返品方針・販売者の特商法表示
- RBA Stripe本番設定、署名Webhook、前払い注文承諾メール、発送連絡、返金試験
- りささんへ注文データを安全に配信し、製造ステータスを適切な権限で更新する接続テスト
- 販売者・製作受託者の契約成立
