## 5. SNS・JOURNAL導線

- 投稿の4系列：問題提起30%、解決策30%、活動の証拠25%、支援参加15%。これは**検証用仮説**でありInstagram Insightsから最適化する。
- 問題提起だけで終わらず、無料解説→活動実績→任意の加入案内へ。
- 投稿例：出場機会、チーム選び、試合判断、練習設計、地域の育成機会。選手・学校・個人を攻撃しない。
- Instagramプロフィールの第一リンクは公式の整理済み入口。Linktreeは旧イベント・旧プラン・404を棚卸ししてから編集。
- JOURNALの高流入記事末尾に、関連する無料記事とメンバーシップを1箇所ずつ。記事を無理に有料化しない。
- 過去参加者・LINE・オープンチャットへは、目的に適合する同意がある場合に限り案内。DNC、停止希望、過去の不達を尊重。無断の名簿転用・一斉送信をしない。
- 既存Square支援者には「感謝と活動報告」を優先。noteへの移行営業や解約誘導はしない。

## 6. 計測仕様

GA4等の既存同意・プライバシー設定に従って匿名のイベント計測を実装する（新規追跡技術の無断追加はしない）。

| イベント | 意味 |
|---|---|
| `membership_page_view` | 会員紹介ページ閲覧 |
| `membership_cta_click` | note既存加入ページへクリック |
| `membership_faq_open` | 不明点の閲覧 |
| `membership_source` | UTMに基づく流入元 |
| `membership_join_verified` | note側の加入証憑と照合できた人数（推測で計上しない） |
| `membership_cancel_verified` | note/Square側で確認済みの解約 |

主要KPI：①訪問→CTAクリック率 ②クリック→確認済み加入率 ③翌月継続率 ④実収入 ⑤コンテンツ提供達成率。
各指標は媒体別・期間別に分け、クリックを購入に換算しない。支援者個人情報は公開ダッシュボードに載せない。

## 7. 30日運用

**Week 1**：現行ページ・Linktree・note・SquareのURL/料金/解約/加入の手動監査。既存支援者の請求保護。2本の記事と月次レポートの編集カレンダー確定。

**Week 3**：対象別導線（保護者/指導者/支援者）をA/B比較。表示数・クリック数・実加入を別々に記録。
**Week 4**：継続率と実加入を確認。成果が弱ければコピー/FAQ/導線を修正。既存契約や料金を変更しない。
