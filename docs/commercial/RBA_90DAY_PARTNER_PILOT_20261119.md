# RBA｜企業90日パートナー実証：営業・契約・履行管理標準（2026-11-19）

公開・商談用のモデル提案。現在の契約成立、協賛額の確約、実施企業や活動を表示しない。

## 目標
継続性のある協賛・法人研修・現物提供案件を、初回商談→提案→書面合意→請求→履行→納品確認の順に管理する。既存企業の無断再送、過去の断り、配信停止の意思を尊重する。

## 標準提案（契約前の参考条件）
- 期間：初回90日。開始日は双方の書面合意後に特定する。
- 協賛参考額：月額11,000円（税込）の3か月、計33,000円（税込）。現行広告メニューの参考値であり、契約・課金の自動開始ではない。
- 基本想定：合意した媒体に企業名や許諾済みロゴ等を掲載、掲載確認、期末に掲載URL・発信回数・活動実績を報告。計画段階では媒体と表示方法を仮置きする。
- 別途：現地イベント開催、交通・宿泊、スタッフ稼働、会場費、撮影、特注商品、受賞景品、翻訳等は都度見積と承認。未承認の追加費を発生させない。
- 成果保証をしない：来場人数、売上、問い合わせ、SNSリーチ、海外チーム参加、選手の成績、企業露出の総量。
- 個人情報：未成年選手や家族の氏名、連絡先、健康、写真、映像をスポンサーへ自動提供しない。広告目的の肖像使用は別途の明示的同意と必要な権利処理を行う。
- 法律・表示：協賛企業の広告内容は事前確認し、スポンサーシップを明示。寄付控除や協会の公認と誤認させない。

## 見積・契約準備の確認項目
- [ ] 相手方商号・所在地・契約締結権限と担当窓口
- [ ] RBA側の正式な契約主体名（法人格・個人事業等は実態に従う）と適格請求書の扱い
- [ ] 期間、金額、消費税表示、請求日、支払期限、支払方法、入金確認
- [ ] 対象活動・媒体・紹介文・ロゴの使用権と承認・修正の期限
- [ ] 実行上の担当者、個別イベントが中止・延期した場合の代替提供と返金・精算条件
- [ ] 各成果物の納品日、受領・検収方法、修正回数、成果報告の形式
- [ ] 機密・個人情報保護・知的財産・第三者権利・再委託・保険など必要事項
- [ ] 双方の書面合意まで、PR・決済リンク・自動課金を開始しない
- [ ] 納品後、請求・入金・実施レポート・先方受領確認を照合

## 営業の質を守る
1. 現在の連絡履歴（Gmailの宛先・ドメイン・企業名）、送信拒否・返信不要の意思を確認し、重複新規営業を防ぐ。
2. 企業の公式サイトから、事業内容と連絡先を直接確認。公開先でないアドレスを推測しない。
3. 「新規営業」は提案送信であり「商談成立」「契約締結」と区別。商談相手から承諾があっても発注・着金・履行まで別ステータス。
4. 断りの返信があった案件には追撃しない。適切な相談分野が違う場合は強引に拡張しない。
5. 営業資料に参加者個票や健康情報を掲載せず、成果は集計値と事実資料に基づく。

## 営業ステージ（このリポジトリに個人の顧客台帳を保存しない）
LEAD_VERIFIED -> CONTACTED -> REPLIED -> MEETING_CONFIRMED -> PROPOSAL_SENT -> TERMS_AGREED -> AGREEMENT_SIGNED -> INVOICED -> PAID -> DELIVERED -> ACCEPTED

中止・拒否：DECLINED、OPT_OUT、CANCELLED、UNDELIVERABLE を分離。
ステージアップは送信済み証跡、書面合意、入金記録、検収確認等の一次資料がある場合に限る。機密案件の個票は、公開GitHubではなく権限管理された記録で管理する。

## 新規案件の提案メール基本形
件名：【地域の育成機会と企業連携】RBA 90日小規模実証のご相談
相手方の具体的事業活動を一つだけ引用し、RBAの育成理念との接点を明示する。参考条件は月額11,000円×3か月だが、初回は有料提案の是非を確認するメールとして費用負担を確約しない。短い情報交換（15分）を依頼し、不要なら追送しない旨を記載する。

## リリース判断
新ページは提案導線に限る。既存の決済・会員・申込・契約条項へ副作用を与えない。Vercel正規プロジェクト・releaseブランチ・TypeScript・ESLint・モバイル・アクセシビリティを確認するまで公開しない。
