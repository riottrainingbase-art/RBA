# RBA クリニック｜申込・フィードバック時の任意サポート案内（共通運用）

作成：2026年11月19日。月500円／1,000円のnoteを使った、クリニック参加者と保護者への丁寧な任意案内。

## 最優先ルール
- **申込・決済・選手起用・指導評価・フィードバックの回答とサポート加入を絶対に連動させない**。
- 必須チェックボックス、必須購入、初期ONの同意、途中での決済リダイレクトを作らない。
- 既加入者は再加入不要。月500円と1,000円を同時購入するよう誘導しない。
- noteは**本人が選択する月額**であり、単発500円の募金ではない。税控除等の対象と断定しない。
- 参加者は未成年の場合が多いため、連絡先は保護者・成人担当者に限り、未成年者へ直接課金の勧誘を送らない。
- メール配信は同意・停止要請・重複を守る。申込の案内メールに短いサポート欄を添えることと、継続広告メールへの同意を得ることは別。
- イベントの参加費・キャンセル条件・支払方法はイベントごとの公式案内を優先。Torsten国内講習はGoogleフォーム→Square、海外のみUSD Stripe。**noteを別イベントの決済に利用しない**。
- 既存のRBA ID/MY HOME COURT無料登録、D-HUBサブスクリプション、noteメンバーシップは別商品。
- 公式説明 https://riotbasketballacademy.com/ja/supporters 。加入・決済 https://note.com/rba_official/membership/join 。

## 1. 申込フォーム末尾の固定テキスト
> 【RBAの育成活動を応援してくださる方へ｜任意のご案内】
>
> RBAの育成活動を続けるため、月500円からのnote応援メンバーを募集しています。月500円は活動を応援し、月1回の活動・使途報告を受け取るプラン。月1,000円は、応援に加えて月2本の育成・見守り方の実践記事を読むプランです。
>
> **いずれも任意の月額会員**です。今回の申込・参加費・参加条件・選手の評価には一切関係ありません。すでに会員の方は再加入不要です。
>
> 詳細：https://riotbasketballacademy.com/ja/supporters
>
> 決済・更新・退会は公式noteで行います。

### 配置
- フォーム末尾の送信ボタン付近に、**静的な説明文だけ**を置く。
- 送信完了画面に載せる場合は、既存の受付番号・支払い・日時・返信先等の案内が最優先。**その下の短い補足**にする。
- 現時点の確定申込・支払を示すとは限らない。「サポート加入＝申込完了」と絶対に書かない。

件名は元の企画に合わせる。本文には申込状況・料金・会場・移動・持ち物・食事・安全事項を先に記載する。
