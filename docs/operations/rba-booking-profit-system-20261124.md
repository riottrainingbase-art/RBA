# RBA 予約・海外交流・収益運営：販売前ゲートと数字の管理
更新：2026-11-24／実装候補ブランチ feat/rba-booking-rizehope-20261124

## 目的
申込件数やSNS閲覧数だけを増やすのではなく、1件ごとの粗い売上と実際に残る限界利益を把握し、安全・提供可能な企画だけを販売する。既存のRBA ID、Jotform、Stripe、イベントページの導線を維持し、未確認な会場・渡航・参加資格を予約確定にしない。

## 事業の分離
| 区分 | RBAが扱うもの | 決済の条件 |
|---|---|---|
| 育成クリニック・キャンプ | 指導料、開催運営、通訳等、RBAが適法に直接提供する内容 | 正式見積、運営条件、安全、返金規定の承認後に既存決済システムで請求 |
| RIZEHOPE大会 | 国内・海外チームの受付意向、大会運営・競技等 | 最終参加要項・年齢ルール・大会側承認・競技参加費・施設・保険等が揃うまで販売不可 |
| 宿泊・送迎・観光 | 適格な登録旅行業者または各サービス事業者に照会、紹介・連携する | 旅行側が正式契約・見積・集金。RBAは未登録旅行パッケージを一括販売しない |
| 会員・スクール・チーム訪問 | 既存のHOMECOURT、D-HUB、体験受付、チーム相談 | 既存の会員権限・契約・決済に重複課金しない |

## 見込み案件ステータス
一つのチーム／イベント／収益契約につき案件IDを一つ割り当て、外部送信を増やす前に重複を排除する。氏名・選手の健康情報をマーケティング台帳に保存しない。

1. **INTEREST**：成人責任者の希望受付。無料、費用請求なし
2. **QUALIFIED**：対象年齢・同行成人・日程・おおよその人数・目的・予算帯を確認
3. **QUOTE REQUESTED**：会場・講師・交通・食事・宿泊の必要条件と提供事業者を特定
4. **COST VERIFIED**：仕入先の見積日／有効期間／税・キャンセルを照合。RBAの業務原価・予備費を計算
5. **OFFER APPROVED**：実施許可、安全・同意・運営・利益率のゲート通過。書面で正式な販売条件承認
6. **OFFER SENT**：成人の代表者に1通で見積、契約主体、含む・含まない、変更・取消、支払期日を提示
7. **ACCEPTED**：申込・契約条件の明示的受諾。決済システムはこの後で利用
8. **PAID / VERIFIED**：実際の本番Stripe等の決済記録と申込ID／プラン／金額を照合し、重複入金・未決済を解消
9. **DELIVERED / CLOSED**：提供実績、実費、返金・未収、利益、改善点、報告同意を記録

## 単位経済性：利益の計算
このツールで計算するのは会社全体の最終純利益ではなく、**イベント単位の限界利益**。固定共通費・税金・事業全体の現金残高は別会計。

```
RBA見込売上 = RBA参加単価×支払見込人数 + 入金確認済み協賛
直接費 = 会場・備品・スタッフ・RBA出張費 + 参加者数×1人あたり原価 + 予備費
決済費 = RBA参加単価×支払見込人数×参加費決済手数料率（銀行入金協賛には一律適用しない）
限界利益 = RBA売上 - 直接費 - 決済費
限界利益率 = 限界利益 / RBA売上
```

- **目標25%**：既存の「Clinic_営業運営SOP_KPI」シート（2026/10/25計画案）の内部目安に統一。確定した会社全体の目標や法定の会計利益率ではない。イベントごとに適切な目標を決定する
- **最低参加人数・安全定員**：許可・人員・固定費を満たせる人数を事前決定。入金ユニーク人数と見込人数を別々に入力し、安全定員未設定（0）のままでは販売候補にしない
- **残余リスク**：悪天候・渡航遅延・キャンセル・返金・海外送金手数料・為替変動を想定し、予備費と返金原資を確認
- **旅行代金**：海外クラブ→登録旅行会社・ホテル・バス会社の請求はRBA売上に入れず、見せかけの売上増を作らない
- **協賛**：「前向き」「検討中」「書面契約済みだが未入金」は試算内の現金収入に含めない。入金確認済みの協賛額のみ反映する。未入金契約は別の債権台帳で管理する
