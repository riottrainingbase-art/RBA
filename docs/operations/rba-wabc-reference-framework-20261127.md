# RBA Development Framework — 2026-11-27

RBA独自の教育・運営基準案。FIBA/WABC公開資料を参照する。認定・提携・公式資格講座ではない。RBA BLUE #2454D8 / RIOT BLACK #111211 / COURT WHITE #F6F5F1 / STEEL GRAY #6B706F、公式ロゴ原本を維持。

## 参照資料と境界
- WABC [Coaching Courses](https://about.fiba.basketball/en/wabc-documents): Start Coaching, Mini Basketball, Level 1–3の公式入口。
- [Mini Basketball](https://assets.fiba.basketball/image/upload/documents-corporate-mini-basketball-mini-basketball-coaches-manual-eng.pdf): §1.1–1.4発達と個別化、§2.1–2.3ゲーム中心と問い、§3身体発達、§5.2–5.4修正ルール・小人数ゲーム。p33の全員が各試合の少なくとも半分に出場するというミニバス向け提案は、すべての年代・大会のFIBA公式競技規則ではない。
- [Level 1](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf): Coach §1 Roles and Values, §2 Know-how / Planning p42。指導者の役割・行動・自己評価。
- [Level 3](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf): Coach §2.2.1 p35。長中短期の目標と進捗確認。RBAの年間計画への応用であり資格レベルとの等価性はない。
- [2025 Coaching Development Project](https://about.fiba.basketball/en/wabc-coaching-development-project): shooting, ball movement/pace, drive, finishing, switch, penetration defence, Gen Z。テーマ選定の参考。動画内容の逐語転載・公式カリキュラム修了主張はしない。
- [FIBA Safeguarding](https://about.fiba.basketball/en/services/integrity/safeguarding) / [Action Plan](https://about.fiba.basketball/en/services/integrity/safeguarding/action-plan): 安全、予防、教育、報告、対応。RBA内責任者・報告経路・現地規則の実効性は別途確認。

## RBAの8原則
選手中心、個別発達、ゲーム中心、問いと発見、全員の参加、身体と健康、安全と尊厳、指導者の成長。年代は目安。U12でスクリーンに依存しない、早期固定役割を避ける、出場機会を罰として奪わない等はRBAの指導設計として記載する。JBA/大会適用規則の確認を省略しない。年間試合数やリング高などの一律数値をWABCの義務として宣伝しない。

## 12週のRBA独自実践案（対象・期間は調整）
1–2 観察・移動・停止・ピボット・ボール操作
3–4 距離・パス・シュート機会
5–6 1対1のズレから2対2へ
7–8 3対3・4対4のスペーシングと協力
9–10 攻守の切替・回復・身体操作
11–12 実戦観察と振り返り
初期段階からゲームを組み込み、技能練習も必要に応じて用いる。U15/U18の戦術は能力・規則・学習目的に応じて段階導入する。

## 全事業への適用
CLINIC/CAMP: 目標一つ、ゲーム→問い→技能補助→再ゲーム→振り返り。会場・安全・学年・料金を確認。
BACKBONE: 3x3の育成・実践。通常5対5スクールやWABC資格コースと混同しない。
GREAM: 長期計画・交代・休息・学校行事・保護者説明。
UNITED: 所属維持の個人参加型、期間限定。旅行手配の役割・安全・費用を合意後確定。
MY HOME COURT: 無料IDで参加・学びをつなぐ。PLUSは任意の実践・振り返り機能。
D-HUB: 指導者の練習設計、選手の学習、現場ケース、自己評価。教材は独自作成、認証ガード維持。
RTB: 発達と個別状態を踏まえ身体操作・負荷・回復を扱う。診断や復帰許可は医療専門職と連携。

## 開催ごとの運営監査（提案、未実施）
- 事前: 責任成人、相談経路、緊急対応、参加条件、会場・引率・食事・宿泊、規則、保護者連絡、写真同意を確認。健康情報は必要な担当者に限定。
- 当日: 参加者ごとの学習機会を記録、適切な休息、暴言・差別・報復を認めない。危険時は即時停止。得点や勝敗だけで評価しない。
- 事後: 活動時間と待機、交代・参加機会、選手の声、練習課題の変化、次回の修正。集計は匿名・必要最小限。懸念は適切な経路へ報告し記録。
- 指導者教育: 自己評価→相互観察→改善計画。公式WABC研修の受講・推薦・資格付与とは区別。
- 公開監査: 4言語同一意味、認定誤認防止、公式出典リンク、既存決済・認証・開催状態維持。全CIと実表示の確認後に公開判断。

## 監査指標（RBA独自）
各回の実活動分数、待機分数、参加セット数の分布、観察した判断の事例、選手の任意の声、次の改善一つ。目標値は現場条件に合わせて設定し、未成年を順位付けする用途にしない。安全事案の報告件数が少ないことだけで安全を断定しない。
