# RBAクリニック共通運営標準（2026-11-28）
今後のRBA主催・共同開催クリニックに適用する。既に合意した既存日程は無断変更しない。現地主催者と募集前に確認する。

1. 公開前：年代・定員・集合/解散時間・会場・安全責任者・緊急対応・休憩・保護者セッション有無を書面で確認。学校試験日程との衝突を点検。
2. 選手：ウォームアップ→技術・判断→少人数ゲーム→実戦→振り返り。年齢・経験・参加人数に応じて調整、全員の実践・判断・失敗機会を確保。終日開催の昼休憩は原則90分。水分補給、食事、回復を優先し、負荷や暑さに応じて休憩を追加。
3. 保護者：長めの休憩に15〜25分の任意の説明・実演。動きづくり（姿勢、バランス、着地、ウォームアップ）、家族が支える休息と練習環境。選手には休息を確保し、追加参加を強制しない。短時間企画は選手の練習・休憩を削らず前後の別時間または資料で対応。
4. 安全：簡単な説明・実演であり診断・治療・個別リハビリではない。痛みや体調不良では中止し専門職へ相談。保護者が体験する場合も任意・無理のない範囲。
5. 公開ページ：参加区分/時間割、保護者説明の時間と任意参加を掲載。確定前は予定と明記。受付・決済・返金条件と矛盾させない。
6. 当日：責任者が休憩・運営状況を点検し、必要時に時間変更。説明後に簡潔な振り返り・持ち帰りポイントを共有。選手・保護者の個人情報と写真動画は同意と既存プライバシー方針に従う。

最初の適用：愛知豊田 2027/2/23、9:00〜17:00。日程表はサイトの共通コンポーネントで表示。12:00〜13:30は選手の昼食・休息90分、12:15〜12:40は保護者任意セッション。
