## 1. マーケティングの中核
**売るもの**：記事1本ではなく、「日本の育成を仕方ないで終わらせない活動に、月500円から参加できること」。
**加入後の根拠**：「応援だけの500円」「応援＋育成実践記事の1,000円」。選択の自由と退会のしやすさを先に伝える。
**価値の出し方**：①子どもの困りごとを言語化 → ②指導・制度・環境を多面的に観察 → ③小さな改善の具体案 → ④現場報告 → ⑤任意の継続応援。
**約束しないもの**：成果保証、無制限の個別相談、クリニック無料、入会者限定の施設予約、JBA/FIBA等の公認、特定の子への指定寄付・寄附金控除。

## 5. 投稿完成原稿（Instagram/Threads共通）
### P1 感情・理念（保護者向け）
「うちの子が、バスケを嫌いになった。」

その言葉を、育成の仕方がない出来事にはしたくありません。
出場時間、練習のさせすぎ、大人の声かけ。子どもが学び続けられる環境は、作り直すことができます。

RBAは、全国の選手・保護者・指導者と学び、地域や国を越えた挑戦の機会を広げていきます。

**月500円から、この活動を応援してください。**
月1,000円は育成を深く学びたい方のプランです。無理のない範囲で、仲間になっていただけたら嬉しいです。

https://riotbasketballacademy.com/ja/supporters

### P2 専門性・実践（指導者向け）
練習ではできる。試合ではできない。
「メンタルが弱い」と片付ける前に、4つを見直しませんか？

1. 技術：守備がいなくても再現できるか。
2. 知覚：打つ時間・スペースが見えていたか。
3. 判断：打つ・抜く・パスを比較できるか。
4. 環境：普段の練習で相手を見て選べるか。

大切なのは「できない」の理由を、本人の性格に押しつけないこと。
無料のRBA JOURNALでも育成の考えを共有しています。
もっと具体的な観察・練習設計を継続して学びたい方には、月1,000円のnoteメンバーシップがあります。

https://riotbasketballacademy.com/ja/supporters

### P3 実績・活動継続（参加者・一般向け）
1回のクリニックで、すべては変わりません。

だからRBAは、開催して終わりではなく、その場で得た学びを次の練習と次の挑戦につなげていきたい。

「月500円だけでも応援できますか？」
もちろんです。無理をする必要はありません。

・月500円：活動の応援、月1回の活動・使途報告
・月1,000円：上記に加えて、月2本の育成記事

ご自身に合う形を、公式noteでご確認ください。
https://riotbasketballacademy.com/ja/supporters

### P4 価格・不安の解消
このRBA応援は**買い切り500円ではなく、月額500円**です。
月1,000円の学びプランも月額です。

クリニック参加費、D-HUB、MY HOME COURT、単品noteとは別。
加入していなくても無料のRBA JOURNALは読めます。
すでにnote会員の方は、追加購入前にご自分の契約を確認してください。

納得して参加してくださる方が、長く応援できる仕組みをつくります。
https://riotbasketballacademy.com/ja/supporters

- 限定枠・残席・実績人数の捏造、JBA/FIBA公認の誤認、子どもの写真や声の無断利用。
