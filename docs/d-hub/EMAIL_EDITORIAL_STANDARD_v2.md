## フォント・レイアウト
- Arial/Helvetica + Hiragino Sans/Yu Gothic/Meiryoなどのシステムゴシック体。Webフォントの外部読込・フォントファイル添付をしない。
- 幅620pxを上限とした1列のHTMLメール。本文16px / 行間1.85 / 文字左揃え。見出し30px（携帯27px）、小見出し20px。
- 黒背景のロゴヘッダー、見出し前の短い英字ラベル、01/02/03のナンバー付きセクション、薄いグレーの罫線、黒の会員HOMEボタン1つ。
- 角丸、絵文字、大きな装飾、色付きの煽り見出し、外部トラッキング素材は使わない。主要CSSはインラインに置き、端末差によるフォントの変化は許容する。

## 編集のルール
1. はじめ：「会員の皆さま、いつもありがとうございます。RBAの西尾です。」
2. 本文：です・ます調で、1段落に1論点。学術用語は最初に日本語で補う。断定は根拠がある範囲に限る。
3. 文章の骨格：「根拠を読む → RBAの解釈 → 練習で1つ試す → 観察・振り返り」。過剰な勧誘や「世界基準」等の無根拠な誇張をしない。
4. 資料を扱う場合、著者が言ったこと、資料にある事実、RBAの応用案、限界を区別。著者・資料名・年・ページ・閲覧条件を末尾に記す。
5. 許諾を確認していない講義スライド・PDF・動画の添付は禁止。読者の名簿・決済情報は転載しない。
6. 既存会員への連絡には原則追加購入を求めず、必要な時だけ実際に利用できる会員HOMEを示す。
7. 送信の前に直近の既送履歴と有効会員資格を確認する。同一教材を説明なしに二度配信しない。

## メールの4分類
- **WEEKLY LETTER**：学習の要点＋今週の練習1つ＋振り返り。
- **COACH NOTE**：講師・研究等の一次資料を読み解き、出典・RBA解釈・応用案を分けて解説。
- **RESEARCH NOTE**：研究対象、方法、結果、限界、練習応用。
- **MEMBER UPDATE**：確定済みの制度・運営事項、対象会員、必要な操作、問い合わせ。

共通の件名は `【D-HUB COACH LAB】テーマ｜更新` または `【D-HUB COACH LAB】テーマ｜解説` とし、絵文字や過剰な記号を入れない。

## 配信と公開の境界
このドキュメントは編集・デザインの正本。更新自体はメール送信やWeb本番公開を伴わない。本文の作成→会員照合→Gmail/配信サービスに設定→実端末で確認→正式送信は別工程とする。既送メールの再編集・再送はしない。
