# COACH LABメール送信前の品質チェック
- [ ] 有効なCOACH LAB会員のみ。PLAYERSや他の営業CRMとは分離する。
- [ ] 過去の同内容メールを検索し、重複送信しない。
- [ ] 件名・プリヘッダー・本文が実際の教材と一致する。
- [ ] 所属や役職・日時・料金などの事実は確認済みである。
- [ ] 著者の一次資料とRBAの解釈を明確に分け、原本再配布権限を点検する。
- [ ] 研究資料なら著者、年、書誌情報、限界がある。
- [ ] 観察できる練習課題を一つ示している。
- [ ] 会員HOMEの遷移先とログイン手順を確認した。
- [ ] 320/390/620/760pxで横はみ出しがない。ロゴ非表示時もブランド名が読める。
- [ ] 色・余白・文字サイズ・署名が共通テンプレートに沿う。
- [ ] 本文内に【要編集】などのプレースホルダーが残っていない。
- [ ] 送信許諾・配信停止希望を確認する。
- [ ] 送信は独立した操作。原稿・下書きを作っただけで送信済みと報告しない。
- [ ] 送信後に受信エラーと個別の重複を確認する。

※GitHub上の変更はメール送信でも本番サイト公開でもありません。
