## Founder weekly target

- 8–12h selected coaching/delivery
- 4–5h programme/development doctrine
- 3–5h strategic partnerships
- 2–3h content/doctrine approval
- <= 3h administration and exception review

## Delegation rules

1. If a task repeats twice, define the state transition.
2. If it repeats three times, automate or delegate it.
3. If structured data can resolve a task, founder should not receive it first.
4. Founder speed is not a valid ownership rule.
5. An exception without a non-founder owner is a design defect.
6. Copying data from email/LINE into a spreadsheet is a signal to redesign the workflow into the system of record.
