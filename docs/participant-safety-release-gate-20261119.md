# RBA｜保護者フィードバックを反映した遠征・キャンプ・クリニック運営ゲート

起票：2026-11-19。対象：RBA主催の国内外キャンプ、遠征、RBA UNITED、クリニック。
目的：保護者が費用・移動・引率・宿泊・安全を判断できる情報を事前に提供する。2026-11-18のMY HOME COURTご意見を受けた改善。個人の氏名や返信原文は転載しない。

## 基本原則
1. 開催予定日が存在することは、会場・宿泊・引率・移動・安全管理が**確定**したことを意味しない。
2. 会場や安全体制の重要事項が未確定の企画は、正式募集・決済を「安全に公開可能」とみなさない。意向調査／事前相談のみとして区別する。
3. 参加者へ確定と伝える前に、一次資料（施設回答、手配確認、契約、料金表、保険、現地担当者）を参照する。見積もりと予約確定を混同しない。
4. 既存申込者の契約条件や取消・返金権を後から不利に変更しない。関連ページ `/ja/cancellation` を優先する。
5. 参加しにくい地域の声を集め、関東・東北・北海道等を含めた年間の開催候補として整理する。均等開催の確約はしない。

## 募集公開の必須確認（開催案件ごとに証跡を保管）
- [ ] 日付、時間帯、会場名・住所、集合／解散場所、会場側の使用許可
- [ ] 参加区分、年齢、定員、参加費（税込）、内訳、追加費、支払い方法、参加確定条件
- [ ] 宿泊あり／なし、施設名、部屋・監督体制、食事提供者、宿泊手配の契約主体
- [ ] 空港・駅・施設間の移動区間、送迎の有無、運転者・車両・座席・保険、自己手配範囲
- [ ] 引率人数・担当責任者・受入チームとの責任分担、連絡手段、未成年の単独移動の扱い
- [ ] 緊急連絡網、傷病時対応、医療機関との連携、施設／団体の保険補償と限界
- [ ] 食物アレルギー・服薬・配慮事項の聞き取り方法、申告期限、提供者との照合／対応可否
- [ ] 荒天・交通障害・参加人数の変動時の実施判断、連絡方法、変更・中止・返金方針
- [ ] 個人情報の最小取得・閲覧権限・写真同意・健康情報の安全な取扱い
- [ ] 募集ページ、申込フォーム、決済画面、参加確定メールでの説明整合性

## 案内の目標タイミング
- 宿泊／遠征企画：開催30日前を目安に重要条件の確定状況を案内する。未確定なら「未確定」として責任者と再確認期限を開示する。
- 開催14日前を目安に、未確定事項の解消、参加者ごとの支払・参加区分、引率・送迎・アレルギー申告、必要書類を点検する。
- 開催72時間前を目安に、最終案内の既達／未達を全件照合し、未達者へ個別連絡する。重大な安全条件が未確定の場合は延期・縮小・中止を判断する。
- 変更が出た場合は、判明後速やかに対象家庭へ差分・影響・選択肢を案内し、メール等で到達を確認する。既存契約の権利は維持する。

## 保護者向け案内テンプレート（個別に事実確認して使用）
件名：【RBA・開催名／開催日】参加前のご案内／確定事項と確認中の事項

ご参加ありがとうございます。安心して準備いただけるよう、確認済みの事項と調整中の事項を分けてお知らせします。

【確定事項】開催日、時間、会場・住所、集合・解散、参加区分、料金・支払状況、担当窓口
【調整中】事項名・参加者への影響・確認予定日・担当者（「未定」と明記）
【宿泊／移動】主催者が手配する範囲／各ご家庭でご準備いただく範囲
【安全・健康】当日の緊急連絡、健康・アレルギー申告方法と期限、対応可能範囲
【変更・返金】該当企画の条件と `/ja/cancellation` への案内
【ご返信いただきたい事項】必要なものだけを安全な方法で伺う

※ 個別の健康情報・未成年の旅程・携帯番号等は公開ページやGitHubへ記録しない。

## 受領した声からの改善点
- 開催地：沖縄・関西だけでなく、関東・東北・北海道にも開催機会を検討
- 国際交流：台湾・マレーシア・韓国の希望を地域ニーズとして集計
- 安全：引率・送迎・アレルギー・保険の確約と未確定を分ける
- 信頼：案内の遅延と直前変更に関する説明責任を明確化

## 公開前QA
- イベント個別ページに確定・調整中・終了の状態区分があるか
- 金額や開催地が誤って確定と表現されていないか
- 申込フォームと支払ページで未確定の安全条件に抵触しないか
- 既存参加者の取消・返金条件を変更していないか
- モバイル閲覧、リンク、可読性、a11y、TypeScript/ESLint/既存テスト
