# RBA JOURNAL・公式note・MY HOME COURT｜編集・商品区分ポリシー

策定：2026-11-19｜適用：RBAの日本語発信・サイト導線

## 一文で伝える

- **RBA JOURNAL**：育成の根拠・公式ガイドライン・RBAの解釈を分けて、**無料で理解する公式ライブラリー**。
- **RBA公式note**：代表の問題提起・現場記録・活動報告・より詳しい実践を、**無料／有料記事で掘り下げる読み物**。任意の月額応援もnote内で扱う。
- **MY HOME COURT**：記事やクリニックから得た気づきを**自分の練習・記録・次の活動につなげる**。無料RBA IDを基本とし、一部有料機能は別契約。
- **D-HUB**：選手・指導者など会員向けの継続的な学び・交流。上記の別プランと自動で共通権限にはならない。

## 編集基準の明確化

| 観点 | JOURNAL | 公式note |
| --- | --- | --- |
| 核心 | 根拠を整理・読み返しやすい学習 | 現場で見たこと、意見の背景、実践の深掘り |
| おもな読者行動 | 困りごとを検索→理解→次の一歩 | 問題意識に共感→考察→応援または実践記事 |
| 価格 | 公開記事は無料 | 無料記事、一部単品有料記事、任意の月額会員 |
| 筆致 | 感情と事実の区別、原典への参照、限界・改訂日 | 代表の一人称や現場の経験を主軸に、推測と事実を区別 |
| 見出し | 具体的な問い・読者の検索意図を反映 | 論点・ストーリー・経験に基づく切り口 |
| 記事構成 | 要約→背景→確認できる根拠→RBAの解釈→できること→参考資料 | きっかけ→現場の経験→考えたこと→読者への問い／実践ステップ |
| CTA | 関連JOURNAL・MY HOME COURT・正式な活動募集へ | 関連JOURNAL・活動情報・任意のnote記事や会員案内へ |
| 更新 | 研究・制度改訂に応じて継続更新。最終確認日も明示 | 現場時点・感想時点を明示し、更新があれば訂正を付す |
| 禁止 | 十分な根拠のない断定、外部サービスでの課金を必須とする説明 | 個人攻撃、未同意の写真・個人情報、架空の会員特典、現場例の誇張 |

研究が含まれるnoteでも、必ず出典や限界を明示する。JOURNALの記事がすべて研究レビューとは限らず、公式資料・安全上の確認を優先する。両媒体で同じ主張を繰り返す場合も全文転載だけで終わらせず、それぞれ独立した読後価値を付ける。

## 同じ題材を使い分ける例

### テーマ：ドリブル練習偏重
- JOURNAL「ボール操作だけでは試合の判断は育たない？ 制約主導アプローチとスキル転移を整理」：課題、根拠、実践条件、限界を無料で説明。
- note「なぜ私は『ドリブルばかりの練習』に違和感を持つのか」：現場の経験、設計上の葛藤、指導者への問いを一人称で掘り下げる。実践メニュー販売があれば中身・適用条件・価格を明示。
- MY HOME COURT「次の練習で試すことを記録」：観察した判断の変化を本人が記録。

### テーマ：出場時間
- JOURNAL「U12の出場機会・競争・発達をどう考える？」：育成指標とチーム運営の一般論を整理。
- note「ベンチの子どもの表情を見て考えたこと」：識別不能な形で共有できる現場の視点と問い。
- MY HOME COURT「試合後の振り返り・次に挑戦したいこと」：本人が記録し、希望に合った活動を探す。

### テーマ：海外育成交流
- JOURNAL「海外交流で何が学べるか、参加前後の設計と安全」：一般原則と事前確認事項。
- note「現場で想像と違ったこと」「遠征後に残る学び」：体験レポート・実践ケース。有料単品は購入前に範囲と条件を説明。
- MY HOME COURT「国際交流への先行意向登録・参加後の学び」：確定開催と意向登録は区別。

## 費用・サービスの分離

1. JOURNAL公開記事は無料で、note購入・有料RBA IDを前提としない。
2. note内の単品有料記事・月額500円/1,000円案内はそれぞれ別の選択肢。**実際の料金・特典・決済・更新・退会はnote最新画面が優先**。
3. MY HOME COURTの無料ID・任意有料プラン・D-HUB・クリニック参加費は別の申込と権限。note購入者を自動でRBAの有料会員として登録しない。
4. noteリンクのクリック数を入会数・売上とみなさない。公開記事閲覧数と有料入会数は別集計にする。
5. 「有料なら必ず試合に出られる」「受講で資格取得」「会員だから参加枠確保」等の根拠のない特典・成果を約束しない。

## 1テーマの発信フロー

- **① JOURNAL**：読者の悩みを解決する無料の記事を先に用意。核心情報を有料側へ隠さない。
- **② note**：編集後記・代表の問題意識・現場の話。一般記事は無料、有料記事は*独立した追加価値*があるものに限定。
- **③ MY HOME COURT**：記録・振り返り・活動検索に接続。必要ならD-HUBへ、契約条件を明示して任意で案内。
- **④ クロスリンク**：JOURNAL→noteは「より深い現場の視点（外部note、無料/有料）」、note→JOURNALは「根拠の整理（無料）」と明記。リンクだけで課金や会員連携を仮定しない。

## 運用上の優先指標

1. JOURNAL：検索経由・記事閲覧・関連記事への移動・読後に行動へ進んだ数。
2. note：無料記事から有料記事・会員案内への移動、実際の購入・継続はnoteの管理画面でのみ確認。
3. MY HOME COURT：初期設定、記録完了、実際の企画申込。メール配信同意は別管理。

発信の差別化は、課金への強制でなく**読者にとっての価値の違い**を明示するために行う。不要な営業メールや大量の通知は行わない。
