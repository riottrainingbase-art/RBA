# RBA 日本語編集基準

更新: 2026-10-01

## 基本

RBAの日本語は、理念を大きく見せるためではなく、選手・保護者・指導者が「何のページか」「自分は何をすればよいか」をすぐ理解できることを優先する。

## 避ける表現

- 「次の一歩」「次の機会」「育成機会」を同じ画面で繰り返さない。
- 「〜につなげる」を連続して使わない。
- 「アップデートする」「Pathway」「Development Environment」など、自然な日本語で足りる箇所に英語を持ち込まない。
- 「世界では〜」「海外では〜」を大きな主語にしない。
- 「圧倒的」「革新的」「唯一」「最先端」など、根拠のない自己評価を使わない。
- 「〜するための場所です」「〜を一つにつなぎます」の連続を避ける。
- 子どもの活動について、企業向け事業資料のような「価値提供」「エコシステム」「ユーザー獲得」等を表面のコピーに出さない。

## 推奨

抽象語より、実際の行動を書く。

悪い例:
「育成機会を発見し、成長を次の挑戦へつなげる。」

良い例:
「参加できる活動を探す。気になったことを読む。練習で試す。終わったら振り返る。」

悪い例:
「指導をアップデートする。」

良い例:
「次の練習で何を変えるか考える。」

悪い例:
「グローバルな育成環境へアクセスする。」

良い例:
「海外のチームと交流する。各国の育成制度を知る。」

## WORLD MAP

順序:
1. 資料から確認できること
2. この制度を見る意味
3. 日本の現場で考えたいこと
4. 一次資料

制度を褒める文章から始めない。
国の優劣にしない。
RBAの意見を事実のように書かない。

## MY HOME COURT

会員ホームで最初に伝えることは機能一覧ではない。

- 今日・今週やること
- 参加できる活動
- 読みたいもの
- 最近の経験
- 次に試したいこと

同じ役割のカードを二つ置かない。

## D-HUB

「学ぶ」だけでは抽象的。
READ → PLAN → COACH → REVIEW は内部構造として残してよいが、本文は以下のように書く。

「背景を知る」
「自分の練習に置き換える」
「実際に試す」
「何が起きたか振り返る」
「次の練習で変える」

## Partner

「認定」「優良」「安全なクラブ」など、RBAが監査・保証していない意味を持たせない。

Partnerは関係性を表す。
指導品質や安全性の保証ではないことを自然な日本語で説明する。

## 最終チェック

声に出して読んだときに、
- 同じ名詞が3文続かないか
- 一文が長すぎないか
- 主語が「RBA」ばかりになっていないか
- 「〜します」が4文以上続かないか
- 英語に置き換えなくても伝わる語を英語にしていないか
- 読者が次に押すボタンの意味が分かるか

を確認する。
