# RBA公開サイトの案内・申込導線監査（2026-10-26）

## 結論

今回追加した目的別入口と参加後ページは機能している。一方、既存ページとの整合性に問題があった。サイトが表示できることと、申し込むための情報が正しいことは分けて確認する必要がある。

## 確認方法と範囲

- 匿名HTTP読取：日本語トップ、選手向け4言語、参加後、活動一覧、開催希望、チーム継続支援、主催相談、協賛、たつのキャンプ、仙台U12の計13ページ。
- 13ページすべてHTTP 200、h1は各1個、Vercelログイン画面でないことを確認。
- 公開ページのブラウザで参加後導線・フォーム入力・コピー成功・再読み込み時リセットを確認。
- 1363pxのブラウザ表示で参加後ページに横方向のはみ出しなし。実機iPhoneおよび印刷結果は今回未確認。
- ソース：稼働中のデプロイに対応するmainから独立した作業ブランチを作成。曜日・会場・料金は現在の仙台U12詳細ページに合わせ、会場予約確定は推定しない。
- 本物の参加申込、決済、メール送信、会員登録は実行しない。これらの完了を監査済みとはしない。

## 良かった点

- 無料の開催希望登録と、実際の参加申込を区別している。
- 開催相談は相談・見積→条件の書面合意→確定の順になっている。
- 振り返りメモは任意入力。保存されないことを説明し、コピーの成功・失敗メッセージを用意。
- 再参加・開催希望・チーム相談・活動記録への入口がある。
- 競技登録・移籍条件とクリニック参加条件を一律に扱っていない。

## 残る確認

1. アクセス解析の有効化とイベント受信。クリック、問合せ、申込、決済、再参加を別々に数える。
2. 3,000人・25地域等の実績表示の集計原票・定義・基準日。今回は公開記載の存在を確認しただけで、数値の裏付け監査は未実施。
3. 各フォームの本送信から確認メール・実決済までの監査。今回は実行していない。
4. 各会場の利用確定・実際の受入枠・次回日程。公開ページの記述から確定とは判断しない。
5. iPhone実機と各OSの印刷・PDF保存。デスクトップでの表示確認を代用しない。

「完璧」「必ず申し込まれる」とは評価しない。今回の改善は、誤案内と迷いを減らし、参加条件の説明まで到達しやすくするもの。
