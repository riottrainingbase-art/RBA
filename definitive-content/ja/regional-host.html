RBA — Youth Basketball Development Platform
RBA REGIONAL HOST

支店を増やすのではなく、
地域に育成の機会を増やす。

地域の指導者、チーム、会場、企業と協力し、その土地に合った活動をつくります。RBAの名前を広げることが目的ではなく、育成方針、安全管理、申込・運営の基本を共有しながら、地域で継続できる形を目指します。

FIELDNETWORKASIA
LOCAL HOST

地域の主催者にお願いしたいこと。

  • 会場確保
  • 地域のチーム・指導者との連携
  • 当日運営
  • 地域での参加者募集
  • 必要に応じた地域企業との連携
RBA

RBAが担うこと。

  • 育成プログラムの設計
  • 募集案内・クリエイティブの支援
  • 指導者の調整
  • 申込・決済導線の整備
  • 運営基準の共有
  • 安全管理と品質確認
HOST STANDARD

続けるために、最初に基準をそろえる。

TRUST

地域の関係者と誠実に連携できること。

SAFETY

未成年者の安全と保護者への説明を最優先にすること。

EXECUTION

会場、募集、連絡、当日運営まで責任を持って進められること。

DEVELOPMENT

目先の勝敗だけでなく、子どもの長期的な成長を大切にすること。
